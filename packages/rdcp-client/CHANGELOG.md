# @rdcp.dev/client Changelog

All notable changes to @rdcp.dev/client will be documented in this file.

## [1.0.0] - 2025-09-25
- First stable release of RDCP client SDK (protocol v1.0)
- Implements all five RDCP endpoints: discovery, control, status, health, and .well-known
- Native fetch implementation (Node 18+), robust error mapping, and schema-validated responses
- ESM/CJS dual builds with types
